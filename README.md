# Online Quiz System

A high-performance, cross-platform online examination and quiz platform for **Desktop** and **Mobile** devices.

## Repository Overview
- **Documentation:** See [ARCHITECTURE.md](file:///c:/Users/piyush/Documents/Online_Quiz_System/ARCHITECTURE.md) for complete architecture, modules, and data flow.
- **Remote Repository:** [Vanshika071417/Online_Quiz_System](https://github.com/Vanshika071417/Online_Quiz_System)

## Core Features
- 🖥️ **Desktop Client**: Comprehensive test-taking with anti-cheat lock, examiner question bank builder, live session proctoring, and analytics dashboard.
- 📱 **Mobile Client**: Fast, responsive quiz taking, review screen, notifications, and instant leaderboards.
- ⚡ **Real-Time Engine**: Server-authoritative timer, auto-sync during network hiccups, and live result calculations.
- 🔒 **Security**: JWT authentication, role-based access control (Admin, Examiner, Student), and focus/blur detection.
